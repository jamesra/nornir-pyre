# Contributing to nornir-pyre

Thank you for your interest in contributing to nornir-pyre!

## Development environment

Use an **umbrella monorepo checkout** with editable installs of sibling packages.
Do not rely on standalone clone + git URL requirements alone.

Full setup (venv, editable install order, run/debug, testing, GPU optional path):

https://nornir.github.io/development/pyre_development.html

Quick run after setup:

```powershell
pyre
python -m pyre
```
